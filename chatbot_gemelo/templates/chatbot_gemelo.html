¿Cómo funciona el Gemelo Digital?
Infraestructura AWS

Este chatbot se apoya en una arquitectura serverless completamente desplegada en AWS:

  • Compute: AWS Lambda (Python 3.12) con FastAPI + Mangum
  • API: Amazon API Gateway (HTTP API)
  • Modelo IA: Amazon Bedrock — Amazon Nova Lite
  • Memoria: Amazon S3 (historial de conversación por sesión)
  • IaC: Terraform + GitHub Actions CI/CD
